# Tiyatronot 🎭

> Türkiye tiyatro sahnesi için dijital oyun günlüğü, eleştiri ve keşif platformu.

Tiyatronot, Letterboxd dinamiklerini Türk tiyatrosunun kendine has yapısına (oyun künyesi, sahne rehberi, matine/suare gösterimleri, kadro varyasyonları) uyarlayan modern, hafif ve Carbon tasarım prensiplerine dayalı bir web platformudur.

- **Tasarım Sistemi:** [design.md](./design.md)
- **Veritabanı & Kimlik Doğrulama:** Firebase Firestore & Google Auth
- **Yönetim:** `/admin` kontrol paneli
